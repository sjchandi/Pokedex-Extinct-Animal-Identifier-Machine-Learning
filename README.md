# **Pokedex-Extinct-Animal-Identifier-ML**

**Pokedex-Extinct-Animal-Identifier-ML** is a **web application** that uses the **camera** (optimized for mobile/phone usage) to **identify extinct animals** in real-time.  
The app leverages **machine learning models** for accurate identification and provides a user-friendly interface for educational and exploratory purposes.

# **Features**

- **Real-Time Camera Detection:** Uses the phone camera to detect extinct animals live and shows description.  
- **Mobile-Optimized:** Designed specifically for smartphones and mobile devices.  
- **Machine Learning Powered:** Identifies extinct animals using trained models from Teachable Machine.  
- **Dataset Integration:** Uses datasets curated from Google for extinct species.  
- **User-Friendly Interface:** Built with ReactJS and Tailwind CSS for responsive and smooth UI.  

# **Tech Stack**

- **ReactJS** 
- **JavaScript**
- **HTML**
- **Tailwind CSS** 
- **Teachable Machine**
- **Google Dataset**
